- Fixed LLM tracing silently dropping span attributes (`Error setting up LLM tracing: Object of type LLMSpecificMessage is not JSON serializable`) when the context contains provider-specific messages — e.g. `OpenAIResponsesLLMService` with reasoning enabled, which round-trips reasoning items as `LLMSpecificMessage`s. `get_messages_for_logging()` in the OpenAI, OpenAI Responses, and the OpenAI/Grok/Inworld realtime adapters (plus the Mistral and Perplexity adapters, by inheritance) now unwraps `LLMSpecificMessage` wrappers into their JSON-serializable payloads, so traced turns keep their `messages`, `tools`, and system instruction attributes.
