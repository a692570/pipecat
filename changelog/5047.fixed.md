- Fixed traced LLM turns losing their `messages`, `tools`, and system instruction span attributes (with an `Error setting up LLM tracing: Object of type LLMSpecificMessage is not JSON serializable` warning) whenever the context contained a provider-specific message — most visibly with `OpenAIResponsesLLMService` with reasoning enabled, which round-trips reasoning items as `LLMSpecificMessage`s. The OpenAI, OpenAI Responses, and OpenAI/Grok/Inworld realtime adapters (plus Mistral and Perplexity, by inheritance) now unwrap `LLMSpecificMessage` wrappers into their JSON-serializable payloads in `get_messages_for_logging()`, so provider-specific messages appear in traces instead of breaking them.
